# Changelog

## [Unreleased]

### Added

- Counters as a tool plug-in: counter groups and their counters, with the
  count, min, max, step, initial value, color and view mode the built-in tool
  holds, Reset and Reset All, a counter blocking what it is linked to until
  it reaches its max, and the built-in tool's pages as layouts. Named in
  English, German, Spanish and French. Built on initiative-plugin-sdk main,
  and needs plug-in API 11.1 (Initiative 0.80.0).
